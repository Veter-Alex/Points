### Назначение программы

Программа предназначена для:

- Парсинга XML и JSON файлов с географическими данными
- Управления базой данных точек в формате CSV
- Работы с данными о городах
- Автоматической обработки больших объемов файлов

---

## ⚙️ Настройка программы

### Основные настройки

#### 📁 Директория для поиска файлов

- Указывает папку, в которой программа будет искать XML/JSON файлы для обработки
- Поддерживается рекурсивный поиск во всех подпапках

#### 📊 Файл базы данных точек (CSV)

- Главный файл для хранения обработанных географических точек
- Можно выбрать существующий файл или создать новый
- При выборе директории автоматически создается файл `AllPoint.csv`

#### 🏙️ Файл данных о городах (TXT)

- Содержит информацию о городах для сопоставления
- Можно выбрать существующий файл или создать новый
- При выборе директории автоматически создается файл `city.txt`

#### 📝 Уровень логирования

Доступные уровни:

- **DEBUG** - подробная отладочная информация
- **INFO** - общая информация о работе
- **WARNING** - предупреждения
- **ERROR** - ошибки
- **CRITICAL** - критические ошибки

## 📄 Работа с файлами

### Поддерживаемые форматы

- **XML** - файлы с расширением `.xml`
- **JSON** - файлы с расширением `.json`
- **SPR** - специальные файлы (сохраняются при очистке)

### Выбор файлов базы данных

#### Для CSV файлов

1. **📄 Выбрать файл** - выбор существующего CSV файла
2. **📁 Выбрать папку** - выбор директории для создания нового файла
3. **Отмена** - отмена операции

#### Для TXT файлов

1. **📄 Выбрать файл** - выбор существующего TXT файла
2. **📁 Выбрать папку** - выбор директории для создания нового файла
3. **Отмена** - отмена операции

## 🔄 Обработка данных

### Процесс обработки

#### 🔍 Этап 1: Поиск папок для обработки

1. Программа рекурсивно сканирует указанную директорию
2. **Находит все папки, где отсутствует файл `data.xlsx`** (уже обработанные папки пропускаются)
3. Отображает количество найденных папок для обработки в журнале событий
4. Формирует очередь папок для последовательной обработки

#### 📊 Этап 2: Обработка каждой папки

Для каждой найденной папки программа:

1. **Сканирует все файлы** в папке и ищет файлы с расширениями `.xml` и `.json`
2. **Парсит каждый найденный файл** и извлекает географические данные
3. **Создает локальные списки** для текущей папки:
   - `points_folder` - успешно обработанные точки
   - `wrong_city_data_folder` - неопознанные города
   - `points_to_edit_folder` - точки без привязки к городу

#### 📄 Данные, извлекаемые из XML/JSON файлов

- **Координаты точки**: широта (latitude) и долгота (longitude)
- **Название города/населенного пункта**: если указано в файле
- **Дата и время**: когда была создана точка
- **Путь к исходному файлу**: для связи с источником данных
- **Дополнительные атрибуты**: в зависимости от формата файла

#### 🧠 Этап 3: Анализ каждой извлеченной точки

##### 3.1 Если в точке **указан город**

1. **Поиск города в базе** `city_data`
2. **Если город найден**: создается полноценная точка с привязкой к городу
3. **Если город не найден**
   - Точка добавляется в список неопознанных городов
   - Формируется шаблон для ручного добавления города в базу
   - Получается информация о стране через координаты

##### 3.2 Если в точке **город не указан**

1. **Поиск похожих точек** в основной базе данных по координатам (в радиусе 0.01° ≈ 1 км)
2. **Если похожая точка найдена**: берется название города из найденной точки
3. **Если похожая точка не найдена**: точка добавляется в список для ручной обработки

##### 3.3 Преобразование координат

- Получение информации о стране по координатам
- Преобразование в систему координат СК-42 (если требуется)
- Формирование описания местоположения относительно областного центра

#### 🗂️ Этап 4

Сохранение результатов для каждой папки

##### 4.1 Создание файлов в обработанной папке

- **`data.xlsx`** — Excel файл с найденными точками (маркер обработки папки)
- **`[имя_файла].kml`** — KML файлы для каждой точки (для просмотра в Google Earth)
- **`report.docx`** — Word отчет с описанием найденных точек и проблемных городов
- **`points_without_city.csv`** — CSV файл с точками без привязки к городу (если есть)

##### 4.2 Структура данных в файлах

**Excel файл (data.xlsx):**

- Дата и время точки
- Координаты (широта, долгота)
- Название города и описание местоположения
- Страна
- Координаты в системе СК-42

**Word отчет (report.docx):**

- Список всех найденных городов с описанием
- Раздел с неопознанными городами для ручной обработки
- Оригинальные тексты из исходных файлов

#### 🗄️ Этап 5: Обновление глобальных баз данных

##### 5.1 Основная база данных точек (AllPoint.csv)

- **Добавление новых точек** из всех обработанных папок
- **Автоматическое сохранение** после завершения обработки всех папок
- **Структура**: все успешно обработанные точки с полной информацией

##### 5.2 База данных городов (city.txt)

- **Ручное пополнение** на основе отчетов о неопознанных городах
- **Сохранение связей** между названиями городов и их координатами

#### 📊 Этап 6: Логирование и отчетность

##### 6.1 Журнал событий содержит

- Путь к каждой обрабатываемой папке
- Названия парсируемых XML/JSON файлов
- Информацию о каждой добавленной точке
- Предупреждения о неопознанных городах
- Пути к созданным файлам (Excel, KML, Word)
- Список точек без городов

##### 6.2 Статистика обработки

- Общее количество папок для обработки
- Номер текущей обрабатываемой папки
- Количество найденных файлов в каждой папке
- Число успешно обработанных точек
- Количество проблемных записей

#### � Особенности логики обработки

1. **Пропуск обработанных папок**: Папки с файлом `data.xlsx` не обрабатываются повторно
2. **Поиск дубликатов**: Новые точки сравниваются с существующими в радиусе 1 км
3. **Автоматическое дополнение**: Точки без города могут получить город от похожих точек
4. **Отложенная обработка**: Проблемные города сохраняются для ручной обработки
5. **Создание связей**: KML файлы связываются с исходными XML/JSON файлами по названию

### Статусы обработки

- **Готов к работе** - программа готова к работе
- **Поиск папок для обработки...** - сканирование директории на наличие необработанных папок
- **Обработка папки X/Y: [путь]** - обработка конкретной папки (X из Y)
- **Парсинг XML: [файл]** - обработка XML файла
- **Парсинг JSON: [файл]** - обработка JSON файла
- **Сохранение результатов...** - создание Excel, KML и Word файлов
- **Обработка завершена** - все папки обработаны, данные сохранены
- **Ошибка обработки** - произошла критическая ошибка

## ❓ Часто задаваемые вопросы

### Как создать новую базу данных?

1. Нажмите кнопку "..." рядом с полем "Файл базы данных точек"
2. Выберите "📁 Выбрать папку"
3. Укажите директорию для создания файла
4. Файл `AllPoint.csv` будет создан автоматически

### Что делать при ошибках?

1. Проверьте правильность путей к файлам
2. Убедитесь, что у программы есть права на запись
3. Проверьте журнал событий для подробной информации
4. При необходимости измените уровень логирования на DEBUG

### Как очистить входную директорию?

1. Перейдите в меню "Команды"
2. Выберите "Очистить входную директорию"
3. Подтвердите операцию в диалоговом окне
4. Будут удалены все файлы кроме XML, JSON и SPR
