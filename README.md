# 🗺️ PointsManager v2.0.0

> **Профессиональное приложение для обработки геопространственных данных с поддержкой 13+ форматов файлов и множественных точек**

**PointsManager** — это мощное настольное приложение для парсинга, обработки и анализа точек наблюдения из XML/JSON файлов с автоматическим определением географического положения и преобразованием координат. Новая версия включает расширенную поддержку форматов, обработку множественных точек в одном файле и значительные архитектурные улучшения.

## 🆕 Что нового в версии 2.0.0

### ⭐ **Ключевые нововведения:**
- ✨ **13 поддерживаемых форматов** (7 XML + 6 JSON) вместо 6
- 🔢 **Множественные точки в одном файле** — автоматическое извлечение всех точек
- 🏗️ **Полная архитектурная переработка** — объектно-ориентированный подход с SOLID принципами
- 🎯 **Улучшенный парсинг** — до 90% меньше файлов в папке "bad"
- 🗺️ **Расширенная база городов** — готовые форматированные данные для 32+ городов

### Поддерживаемые входные форматы

**PointsManager** поддерживает широкий спектр XML и JSON форматов с поддержкой множественных точек:

#### 📄 **XML файлы (7 форматов)**

- **Стандартный формат точек**:
  ```xml
  <point>
      <latitude>55.7558</latitude>
      <longitude>37.6176</longitude>
      <city>Москва</city>
      <datetime>2025-08-14T10:30:00</datetime>
  </point>
  ```

- **DevExpert weather format**:
  ```xml
  <loc lat="55.7558" lon="37.6176" name="Moscow" country="Russia">
      <obs dt="2025-08-14T10:30:00"/>
  </loc>
  ```

- **OpenWeatherMap current format**:
  ```xml
  <current>
      <city name="Moscow">
          <coord lat="55.7558" lon="37.6176"/>
          <country>RU</country>
      </city>
      <lastupdate value="2025-08-14T10:30:00"/>
  </current>
  ```

- **OpenWeatherMap forecast format**:
  ```xml
  <weatherdata>
      <location>
          <name>Moscow</name>
          <country>RU</country>
          <location latitude="55.7558" longitude="37.6176"/>
      </location>
      <forecast>
          <time from="2025-08-14T10:30:00" to="2025-08-14T11:00:00"/>
      </forecast>
  </weatherdata>
  ```

- **🆕 Settings Client format**:
  ```xml
  <settings>
      <client lat="55.7558" lon="37.6176" country="Russia"/>
  </settings>
  ```

- **🆕 Document Items format** (множественные точки):
  ```xml
  <document>
      <item lat="55.7558" lng="37.6176" n="Moscow" country_name="Russia"/>
      <item lat="59.9311" lng="30.3609" n="Saint Petersburg" country_name="Russia"/>
      <item lat="56.8431" lng="60.6454" n="Ekaterinburg" country_name="Russia"/>
  </document>
  ```

- **🆕 HHForecast format**:
  ```xml
  <document>
      <GetHHForecastResult lat="55.7558" lng="37.6176" 
                           cityName="Moscow" country_name="Russia"/>
  </document>
  ```
  </weatherdata>
  ```

#### 📄 **JSON файлы (6 форматов)**

- **WorldWeatherOnline format**:
  ```json
  {
      "data": {
          "current_condition": [
              {
                  "FeelsLikeC": "18",
                  "localObsDateTime": "2025-08-14 10:30 AM"
              }
          ],
          "nearest_area": [
              {
                  "latitude": "55.756",
                  "longitude": "37.618",
                  "areaName": [{"value": "Moscow"}],
                  "country": [{"value": "Russia"}]
              }
          ]
      }
  }
  ```

- **IPApi format**:
  ```json
  {
      "lat": 55.7558,
      "lon": 37.6176,
      "city": "Moscow",
      "country": "Russia",
      "timezone": "Europe/Moscow"
  }
  ```

- **GeoIP format**:
  ```json
  {
      "ip": "192.168.1.1",
      "latitude": 55.7558,
      "longitude": 37.6176,
      "city": "Moscow",
      "country_name": "Russia"
  }
  ```

- **OpenWeatherMap format**:
  ```json
  {
      "coord": {
          "lon": 37.6176,
          "lat": 55.7558
      },
      "name": "Moscow",
      "sys": {
          "country": "RU"
      }
  }
  ```

- **🆕 CityInfo format** (дата/время из метаданных файла):
  ```json
  {
      "cityInfo": {
          "lat": 55.7558,
          "lon": 37.6176
      },
      "localizedNames": {
          "ru": "Москва"
      },
      "country": {
          "localizedNames": {
              "ru": "Россия"
          }
      }
  }
  ```

- **🆕 GeoPlugin format** (дата/время из метаданных файла):
  ```json
  {
      "geoplugin_latitude": "55.7558",
      "geoplugin_longitude": "37.6176",
      "geoplugin_city": "Moscow",
      "geoplugin_countryName": "Russia"
  }
  ```

- **AccuWeather API format**:
  ```json
  {
      "GeoPosition": {
          "Latitude": 55.7558,
          "Longitude": 37.6176
      },
      "LocalizedName": "Moscow",
      "Country": {
          "LocalizedName": "Russia"
      },
      "TimeZone": {
          "Name": "Europe/Moscow"
      }
  }
  ```

### ⏰ Интеллектуальное определение даты и времени

Программа использует гибкую стратегию извлечения временных данных:

1. **Из содержимого файла** — приоритетный метод для большинства форматов
2. **Из метаданных файла** — для специальных форматов и множественных точек
3. **Пустое значение** — если данные недоступны

**Форматы, использующие метаданные файла:**
- CityInfo JSON weather format
- GeoPlugin JSON format  
- OpenWeatherMap forecast XML format
- Settings Client XML format
- Document Items XML format (множественные точки)
- HHForecast XML format

## 🔢 Поддержка множественных точек

**PointsManager 2.0** автоматически обрабатывает файлы с несколькими точками:

- **Document Items XML** — извлекает все элементы `<item>`
- **Автоматическое обнаружение** — определяет формат и количество точек
- **Единый процессор** — обрабатывает каждую точку индивидуально
- **Подробное логирование** — отчет о количестве найденных точек

**Пример обработки множественных точек:**
```
✅ Найдено 3 точки в файле cities_data.xml
� Извлечено 3 точки из 3 элементов
� Обработка точки 1/3: Moscow
📍 Обработка точки 2/3: Saint Petersburg  
� Обработка точки 3/3: Ekaterinburg
```

## 🏗️ Архитектура

**PointsManager 2.0** построен на основе современных принципов разработки:

### 📦 **Модульная архитектура SOLID**

- **🔧 Single Responsibility** — каждый класс отвечает за одну задачу
- **🔒 Open/Closed** — легко расширяется новыми парсерами
- **🔄 Liskov Substitution** — взаимозаменяемые компоненты
- **⚙️ Interface Segregation** — специализированные интерфейсы
- **🎯 Dependency Inversion** — гибкая система зависимостей

### 🚀 **Полная переработка 2025**

**Parsers.py** и **Core.py** были полностью переписаны с использованием ООП:

#### 📖 **Система парсеров:**
- **BaseParser** — абстрактный базовый класс с общей логикой
- **XMLParser** — специализированный парсер для 7 XML форматов
- **JSONParser** — специализированный парсер для 6 JSON форматов
- **DateTimeExtractor** — утилиты для извлечения времени
- **CoordinateExtractor** — утилиты для обработки координат

#### ⚙️ **Система обработки:**
- **CorePipeline** — главный координатор всех процессов
- **FolderProcessor** — обработчик папок и поиск файлов
- **FileProcessor** — обработчик файлов с поддержкой множественных точек
- **PointProcessor** — обработчик точек и привязка к городам
- **ReportGenerator** — генератор всех типов отчетов

#### 🔧 **Вспомогательные утилиты:**
- **CoordinateHelper** — исправленная обработка координат СК-42
- **LoggingMixin** — единая система логирования
- **FileHandler** — работа с файловой системой

### ✅ **Преимущества новой архитектуры**

- 🧪 **Легкость тестирования** — каждый компонент тестируется изолированно
- 🔧 **Простота поддержки** — изменения в одном классе не затрагивают другие
- 🔄 **Повторное использование** — компоненты можно использовать в других проектах
- 📈 **Масштабируемость** — легко добавлять новые форматы и функции
- 🐛 **Надежность** — четкое разделение ответственностей снижает количество багов

## ✨ Основные возможности

### 📁 **Обработка данных**

- 🔍 **Парсинг XML и JSON файлов** с точками наблюдения (поддержка 13 различных форматов)
  - **XML форматы**: стандартные точки, DevExpert weather, OpenWeatherMap current/forecast, Settings Client, Document Items, HHForecast
  - **JSON форматы**: WorldWeatherOnline, IPApi, GeoIP, OpenWeatherMap, CityInfo, GeoPlugin, AccuWeather API
- 🔢 **Множественные точки в одном файле** — автоматическое извлечение всех точек из Document Items формата
- ⏰ **Гибкое извлечение времени** — из содержимого файла или метаданных файла (время создания)
- � **Автоматическая дедупликация** — исключение повторяющихся точек с улучшенными алгоритмами
- 🗂️ **Пакетная обработка** папок с файлами любой вложенности
- 💾 **Резервное копирование** данных с ротацией (10 последних копий)

### 🌍 **Геопространственные функции**

- 🎯 **Автоматическое определение стран** по координатам WGS-84 через countries.geojson
- 🔄 **Преобразование координат** WGS-84 ↔ СК-42 (Гаусс-Крюгер) с исправленной обработкой
- 🗺️ **Автоопределение зон СК-42** (зоны 2-28) с кэшированием трансформеров
- 🏙️ **Расширенная база городов** с автозаполнением данных (32+ новых города готовы к интеграции)
- 📍 **Точки без города** — отдельная обработка с созданием KML файлов и CSV отчетов

### 📤 **Экспорт и отчеты**

- 📋 **Excel (.xlsx)** — структурированные таблицы с полными данными о координатах
- 🗺️ **KML файлы** — для просмотра в Google Earth/Maps (включая отдельные файлы для точек без города)
- 📄 **Word отчеты** — детальная группировка по странам и регионам
- 💾 **CSV экспорт** — для дальнейшей обработки данных (включая специальные файлы для точек без города)

### 🎨 **Интерфейс и удобство**

- 🖥️ **Современный GUI** на базе CustomTkinter с темной темой
- 📝 **Цветное логирование** в реальном времени с уровнями детализации
- 📊 **Прогресс-бар** обработки с детальной информацией о текущем файле
- ⚙️ **Настраиваемые параметры** через settings.txt
- 🔧 **Отладочный режим** с подробным логированием всех операций

## 🚀 Быстрый старт

### Вариант 1: Готовый exe файл (рекомендуется)
1. Скачайте `PointsManager.exe` из папки `dist/`
2. Запустите двойным кликом
3. ✅ Готово! Никаких дополнительных установок не требуется

### Вариант 2: Запуск из исходного кода
1. **Установите Python 3.8+**
   ```bash
   python --version  # Проверьте версию
   ```

2. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/Veter-Alex/Points.git
   cd Points
   ```

3. **Создайте виртуальное окружение**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   ```

4. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

5. **Запустите приложение**
   ```bash
   python main.py
   ```

## 📦 Сборка exe файла

Для создания собственной portable сборки:

```bash
# Активируйте виртуальное окружение
.venv\Scripts\activate

# Установите PyInstaller (уже включен в requirements.txt)
pip install pyinstaller==4.10

# Соберите приложение
python -m PyInstaller --clean .\PointsManager.spec
```

Готовый exe файл будет в папке `dist/PointsManager.exe`
