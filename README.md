# 🗺️ PointsManager v1.0.0

> **Профессиональное приложение для обработки геопространственных данных с графическим интерфейсом**

**PointsManager** — это мощное настольное приложение для парсинга, обработки и анализа точек наблюдения из XML/JSON файлов с автоматическим определением географического положения и преобразованием координат.

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://python.org)
[![Windows](https://img.shields.io/badge/Windows-7%2F10%2F11-blue.svg)](https://microsoft.com/windows)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## ✨ Основные возможности

### 📁 **Обработка данных**
- 🔍 **Парсинг XML и JSON файлов** с точками наблюдения
- ⏰ **Автоматическое время** — использует время создания файла если дата/время отсутствуют в содержимом
- 📊 **Автоматическая дедупликация** — исключение повторяющихся точек
- 🗂️ **Пакетная обработка** папок с файлами
- 💾 **Резервное копирование** данных с ротацией (10 последних копий)

### 🌍 **Геопространственные функции**
- 🎯 **Автоматическое определение стран** по координатам WGS-84
- 🔄 **Преобразование координат** WGS-84 ↔ СК-42 (Гаусс-Крюгер)
- 🗺️ **Автоопределение зон СК-42** (зоны 2-28)
- 🏙️ **База городов** с автозаполнением данных
- 📍 **Точки без города** — отдельная обработка с созданием KML файлов

### 📤 **Экспорт и отчеты**
- 📋 **Excel (.xlsx)** — структурированные таблицы с данными
- 🗺️ **KML файлы** — для просмотра в Google Earth/Maps (включая точки без города)
- 📄 **Word отчеты** — группировка по странам и регионам
- 💾 **CSV экспорт** — для дальнейшей обработки (включая точки без города)

### 🎨 **Интерфейс и удобство**
- 🖥️ **Современный GUI** на базе CustomTkinter
- 📝 **Цветное логирование** в реальном времени
- 📊 **Прогресс-бар** обработки
- ⚙️ **Настраиваемые параметры**

## 🚀 Быстрый старт

### Вариант 1: Готовый exe файл (рекомендуется)
1. Скачайте `PointsManager.exe` из папки `dist/`
2. Запустите двойным кликом
3. ✅ Готово! Никаких дополнительных установок не требуется

### Вариант 2: Запуск из исходного кода
1. **Установите Python 3.8+**
   ```bash
   python --version  # Проверьте версию
   ```

2. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/Veter-Alex/Points.git
   cd Points
   ```

3. **Создайте виртуальное окружение**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   ```

4. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

5. **Запустите приложение**
   ```bash
   python main.py
   ```

## 📦 Сборка exe файла

Для создания собственной portable сборки:

```bash
# Активируйте виртуальное окружение
.venv\Scripts\activate

# Установите PyInstaller (уже включен в requirements.txt)
pip install pyinstaller==4.10

# Соберите приложение
python -m PyInstaller --clean .\PointsManager.spec
```

Готовый exe файл будет в папке `dist/PointsManager.exe`

## 🎯 Использование

### 1. **Подготовка данных**
- Поместите XML/JSON файлы в папки без файла `data.xlsx`
- Приложение автоматически найдет и обработает их

### 2. **Запуск обработки**
- Выберите папку с данными через GUI
- Нажмите "Начать обработку"
- Следите за прогрессом в реальном времени

### 3. **Результаты**
- **Excel файлы** — в каждой обработанной папке
- **KML файлы** — для каждой точки отдельно
- **Word отчет** — сводный отчет по всем точкам
- **Логи** — в папке `logs/`
